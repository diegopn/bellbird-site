01 · Visão geral

O que é o Bellbird

O Bellbird é um aplicativo para GNOME que converte documentos em código LaTeX organizado. O processamento acontece no próprio computador, sem exigir conta ou conexão com a internet para converter arquivos.

O resultado é um arquivo LaTeX que você pode revisar, copiar ou exportar para continuar trabalhando nas ferramentas que preferir.

02 · Formatos e modelos

Escolha um documento e um padrão de saída

Formatos de entrada

O Bellbird abre os seguintes formatos:

  • Word: .docx
  • EPUB: .epub
  • HTML: .htm e .html
  • Markdown: .markdown e .md
  • OpenDocument: .odt
  • Org: .org
  • reStructuredText: .rst
  • LaTeX: .tex
  • Texto simples: .txt

Modelos de saída

Escolha o estilo LaTeX adequado ao seu documento:

  • LaTeX padrão
  • ABNT (abnTeX2)
  • IEEE (IEEEtran)
  • ACM (acmart)
  • Elsevier (elsarticle)
  • Springer Nature (sn-jnl)

03 · Conversão

Converta um documento em LaTeX

  1. Arraste um arquivo para a janela do Bellbird ou escolha Selecionar um arquivo.
  2. Depois que o documento for aberto, escolha o modelo no campo Estilo LaTeX.
  3. Aguarde o processamento. O código gerado aparece na área Saída LaTeX.

Para trocar o modelo, selecione outra opção em Estilo LaTeX. O Bellbird atualiza a saída usando o documento que já está aberto.

Os arquivos devem ter até 10 MiB. Para evitar falhas, confirme também que o arquivo está disponível localmente no computador.

04 · Resultado

Revise, copie ou exporte o resultado

  1. Leia o código na área Saída LaTeX. Os números de linha ajudam a localizar trechos.
  2. Use Copiar LaTeX para copiar o conteúdo para a área de transferência.
  3. Use Exportar LaTeX para salvar um arquivo .tex. O seletor sugere a pasta Downloads e um nome baseado no documento; você pode escolher outro destino ou nome.

Revise avisos e o código antes de usar o resultado. Alguns conteúdos podem ser convertidos em texto simples para manter um LaTeX válido, e documentos com problemas estruturais ou de citação podem precisar de ajustes.

O Bellbird usa os dados de autoria encontrados no documento. Se não houver autor, o resultado indica o local para preenchimento.

05 · Privacidade e limites

Como seus documentos são processados

A conversão é local. O Bellbird não envia os documentos para um serviço na nuvem e não exige conta nem conexão à internet para processá-los.

O que a saída inclui

  • O Bellbird gera um único arquivo .tex; não cria um PDF.
  • Imagens e recursos anexos não são incluídos na saída. Quando disponíveis, as descrições das imagens são mantidas como texto.
  • O Bellbird não compila LaTeX. Para gerar um PDF, abra o arquivo exportado em uma distribuição LaTeX e instale a classe e os pacotes exigidos pelo modelo escolhido.

07 · Solução de problemas

Problemas comuns

O formato do arquivo não é compatível

Confira a lista de formatos de entrada neste manual e selecione um arquivo com uma das extensões compatíveis.

O arquivo não pode ser aberto

Confirme que o arquivo está disponível localmente, que o aplicativo tem acesso a ele e que o tamanho não ultrapassa 10 MiB.

O resultado precisa de ajustes

Revise as mensagens e o código gerado. Recursos não compatíveis podem virar texto simples, e citações ou estruturas LaTeX podem exigir correção manual.

Preciso de um PDF

O Bellbird gera código LaTeX, mas não o compila. Use uma distribuição LaTeX com a classe e os pacotes necessários para o modelo escolhido.

Se o problema continuar, registre os passos que levaram ao erro e a mensagem exibida em Relatar um problema.
