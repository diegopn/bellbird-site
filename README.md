# Bellbird site

Site estático de apresentação do Bellbird, conversor local de documentos para LaTeX.

## Idiomas

- Português (Brasil): https://diegopn.github.io/bellbird-site/
- English: https://diegopn.github.io/bellbird-site/en/
- Español: https://diegopn.github.io/bellbird-site/es/

As páginas compartilham os arquivos de estilo e interação e o ícone em assets/.

## GitHub Pages

O site não precisa de build. Para ativar a publicação, abra Settings → Pages no repositório e escolha Deploy from a branch, branch main e pasta /(root). Depois dessa configuração inicial, cada atualização enviada à branch main é publicada automaticamente.
