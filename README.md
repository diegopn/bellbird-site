# Bellbird site

Site estático de apresentação do Bellbird, conversor local de documentos para LaTeX.

## Idiomas

- Português (Brasil): https://diegopn.github.io/bellbird-site/
- English: https://diegopn.github.io/bellbird-site/en/
- Español: https://diegopn.github.io/bellbird-site/es/

[Manual do usuário (Português)](https://diegopn.github.io/bellbird-site/manual/)

O código fica organizado em src/css/, src/js/ e src/assets/images/.

## GitHub Pages

O GitHub Pages compila o site com Jekyll e publica o conteúdo automaticamente a partir da branch main, sem um workflow de publicação próprio.

Configure uma vez em Settings → Pages: selecione Deploy from a branch, a branch main e a pasta /(root). Depois disso, cada atualização enviada à main é publicada automaticamente.
